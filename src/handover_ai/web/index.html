이 페이지의 근거 묶음

선택한 방식으로 묶은 텍스트입니다. 선택하면 원문 영역을 표시합니다. 배치 분석의 읽기 순서는 제안입니다.

근거를 준비한 뒤 확인하세요.

문서 안에서 근거 검색

현재 정리 방식의 근거를 검색합니다. 검색 순위는 정확도를 보장하지 않으므로 원문을 확인하세요.

근거 준비 후 사용할 수 있습니다.

이전 검색 색인 정리

사용하지 않는 검색용 복제본만 삭제합니다. 현재 색인·원문·근거·검토 이력은 보존됩니다.

근거 기반 인수인계 초안

현재 문서의 검색 근거에서 원문을 발췌합니다. 분류와 순서는 제안이며, 검토 후 사용하세요.

문서·근거·검색 색인을 준비해 주세요.
