## 계속 유지할 조건

- SQLite가 기준 저장소다. ChromaDB 내용만으로 근거가 유효하다고 판단하지 않는다.
- `page-lines-v1:chars=800` 결과는 비교 기준선으로 보존한다. 새 규칙은 새 버전으로 만들고 과거 Chunk/Block ID를
  삭제하거나 덮어쓰지 않는다.
- OCR/구조/색인/문서 생성의 완료 상태를 구분한다. **근거 준비됨**은 검색 가능 상태가 아니다.
- Chunk의 800자는 토큰 수가 아니다. 검색은 실제 토큰 길이로 창을 나눠 평균하며 전처리 정책은 색인 버전에 포함한다.
- 모델 비교·코드 변경 평가는 새 출력 폴더로 분리하고 합성 결과와 실제 문서 결과를 따로 기록한다.
- 제어 문형 규칙은 모든 우회에 대한 보장이 아니다. 명령형 업무 절차를 일괄 차단하거나 자동 승인하지 않는다.
- 새 코드 주석은 필요한 설명만 간결한 한국어로 작성한다.
