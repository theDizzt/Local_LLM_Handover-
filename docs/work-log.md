## 2026년 10월 5일 — 수동 정답 기반 배치 분석 평가 도구

- 현재 OCR을 읽기 전용 SQLite 스냅샷에서 평가 JSON·원문 PNG·HTML 대조 자료로 내보내기.
- 원문 SHA-256, 문서/OCR ID와 정답 상태·읽기 순서·분류 계약 추가.
- 미작성 정답 제외, 정답 작성률·분류별 정밀도/재현율/F1·순서 완전/선후 관계 지표 구현.
- 선후 관계 역전 계산은 O(n log n); 빈 페이지·없는 분모로 점수가 부풀지 않도록 처리.
- 잘못된 원문 버전·Block ID·누락/중복과 분석기 원문 보존 위반을 명시적으로 거절.
- 수동 합성 fixture 6종 평가: 분류 정답 14/29개, 지정 분류 14개 및 순서 관계 86쌍 일치.
- 전체 테스트 97개 통과/선택 OCR 1개 건너뜀, Ruff 및 Edge 오프라인 HTML 표시 검증 통과.
- 실제 업무 문서 품질을 측정한 결과는 아니며 실제 정답 작성·교정 편집은 후속 작업.
